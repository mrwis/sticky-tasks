# 逍遥便利贴 · 任务清单（Python / tkinter 版）

一个 Windows 桌面便利贴任务清单：**四象限（艾森豪威尔矩阵）+ 子任务 + 计时 + 每日复盘**。
零第三方依赖、数据明文、常驻内存约 30 MB。

## 两版并存

同一个设计有两套实现，**共用同一份 `tasks.json`**，放在同一目录下可以互相读写：

| | 本仓库（Python 版） | 另一版（aardio 版） |
|---|---|---|
| 目录 | `sticky-tasks/` | `aardio-sticky/` |
| 实现 | Python 标准库 + tkinter | Win32 原生窗口 + GDI+ 自绘 |
| 入口 | `sticky.pyw` | `main.aardio` + `default.aproj` |
| 运行 | 双击本文件，或 `pythonw sticky.pyw` | aardio IDE 打开 `default.aproj` 按 F5 |

任务字段、备注换行、四象限配色、快捷键、几何尺寸两版逐条对应 ——
**任一边改了设计，另一边要跟着改**。两版源码顶部各有一份「代码导读」，
说明阅读顺序、必须弄懂的机制和常见改动怎么做，改代码前先读它。

## 怎么运行

- 需要 Python 3（Windows 版自带即可），**不需要 pip install 任何东西**。
- 双击 `启动便利贴.bat`，或命令行 `pythonw sticky.pyw`。
  用 `pythonw` 启动就不会带出黑色控制台窗口。

## 功能一览

- **四象限卡片墙**：P0 重要且紧急 / P1 重要不紧急 / P2 紧急不重要 / P3 不紧急不重要，
  可切「列表」视图平铺按时间排。
- **拖拽五件事**：改优先级、调同组顺序、拖到卡片上半张变子任务、子任务排序、
  子任务拖到空白提升成独立任务。
- **子任务**：卡面显示完成进度，右键可编辑 / 上下移 / 完成 / 删除。
- **备注**：卡片上直接显示，双击就地改，空备注时有一行浅灰的「＋ 备注」入口。
- **截止日期与重复**：逾期 / 今天有标签提醒；每天 / 每周 / 每月 / 每年自动排下一次。
- **计时**：点右下角药丸开始暂停，按日期分桶累计，可看今天 / 本周 / 近 7 天 / 全部。
- **统计与复盘面板**：各象限投入、完成趋势、12 周完成热力图。
- **筛选与搜索**：全部 / 未完成 / 今天要做 / 已逾期 / 计时中 / 已完成；按标题、备注、
  子任务文字实时过滤。
- **回收站 + 撤销**：删除进回收站可捞回，`Ctrl+Z` 撤销上一次删除。
- **备份与导入**：每天自动备份到指定文件夹、可设保留天数；可从任意备份恢复。
- **到点提醒**：今天到期 / 已逾期的任务主动弹窗。窗口可置顶。

完整的按钮说明和快捷键表在程序里按 `F1` 打开「使用帮助」。

## 数据

任务明文存在程序目录的 `tasks.json` 里（顶层 `{v, ui, tasks, trash}`），
不上传、不加密，随时可以用记事本打开看。换电脑把这个文件夹拷过去就行。

程序自己产生的调试图、构建产物、日志、数据备份和临时文件都不入库（见 `.gitignore`）。
