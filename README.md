# 逍遥便利贴 · 任务清单（Python / tkinter 版）

一个 Windows 桌面便利贴任务清单：**四象限（艾森豪威尔矩阵）+ 子任务 + 计时 + 每日复盘**。
零第三方依赖、数据明文、常驻内存约 30 MB。

## 两版并存

同一个设计有两套实现，**共用同一份 `tasks.json`**，放在同一目录下可以互相读写：

| | 本仓库（Python 版） | 另一版（aardio 版） |
|---|---|---|
| 目录 | `sticky-tasks/` | `aardio-sticky/` |
| 实现 | Python 标准库 + tkinter | Win32 原生窗口 + GDI+ 自绘 |
| 入口 | `sticky.pyw` | `main.aardio` + `default.aproj` |
| 运行 | 双击本文件，或 `pythonw sticky.pyw` | aardio IDE 打开 `default.aproj` 按 F5 |

任务字段、备注换行、四象限配色、快捷键、几何尺寸两版逐条对应 ——
**任一边改了设计，另一边要跟着改**。两版源码顶部各有一份「代码导读」，
说明阅读顺序、必须弄懂的机制和常见改动怎么做，改代码前先读它。

## 怎么运行

- 需要 Python 3（Windows 版自带即可），**不需要 pip install 任何东西**。
- 双击 `启动便利贴.bat`，或命令行 `pythonw sticky.pyw`。
  用 `pythonw` 启动就不会带出黑色控制台窗口。

## 打包成 exe（免安装，直接发给别人）

想让日常使用不碰源码、或者发给没有 Python 的朋友，就打包成单文件 exe：

```bat
:: 1. 建一个构建环境（只做一次）
python -m venv _build_venv
_build_venv\Scripts\python.exe -m pip install pyinstaller pillow

:: 2. 打包
_build_venv\Scripts\python.exe tools\build_exe.py
```

产物在 `dist\`：

| 文件 | 说明 |
|---|---|
| `逍遥便利贴.exe` | 单文件，约 9.7 MB，双击即用，不用装 Python |
| `使用说明.txt` | 给拿到 exe 的人看的：数据存哪、怎么换电脑 |

三件需要知道的事：

- **数据存在 exe 旁边的 `tasks.json`**，不写注册表、不写 `%APPDATA%`。
  所以分享时**只发 exe 就行** —— 每个人第一次打开都会拿到自己那份示例数据，
  不会带上你的任务。反过来，自己换电脑就把 exe 和 `tasks.json` 一起拷过去。
- **exe 别放在 `C:\Program Files` 这类需要管理员权限的目录**。那里写不了文件，
  任务会存不下来（程序会弹一次提示说清楚原因，但最好一开始就放桌面或 D 盘）。
- 打包脚本会**排除掉整个网络 / 加密栈**（这程序一个字节都不联网），
  于是 openssl 那两个 dll（合计 7.5 MB）不会进产物 —— 体积直接小一半。

`build/`、`dist/`、`*.spec` 都在 `.gitignore` 里：产物随时能重建，不必进仓库。
图标由 `tools/make_icon.py` 生成（改两行颜色重跑即可），版本信息读源码里的 `APP_VERSION`。
打包完可以用 `tools/verify_exe.py` 自动验一遍（12 项：能不能起来、数据落在哪、
外面改的 json 读不读得到、产物里有没有夹带你的真实任务）。

### 日常用的那份放哪

`dist\` 是**构建产物目录**，不该拿来日常用 —— 它在 git 仓库里面，
哪天 `git clean -xdf` 一下，被忽略的 `tasks.json` 会跟着一起没。
所以日常那份单独放在**项目上一级的 `成品-便利贴\`**（不在任何仓库里）：

```
成品-便利贴\
    逍遥便利贴.exe      ← 双击这个
    tasks.json         ← 你的任务，只属于这一份
    使用说明.txt
```

`tools\build_exe.py` 编译完会**自动把新的 exe 和 使用说明.txt 拷过去**
（目录存在才拷，**绝不碰 tasks.json**），省得每回"打完了忘了拷"。
这样"用"和"改"就分开了：日常增删任务不会在 `git status` 里冒出任何东西，
改坏了源码也不影响正在用的那份。想分享给别人，把 exe 单独拷出去就行。

## 功能一览

- **卡片墙**：出厂是四格（P0 重要且紧急 / P1 重要不紧急 / P2 紧急不重要 / P3 不紧急不重要），
  两列排下来；可切「列表」视图平铺按时间排。
- **象限可以增删改名（1~8 个）**：四格是出厂设置，你可以改成 工作 / 学习 / 娱乐 / 生活，
  也可以再加 健身 / 家人 —— 要六个、七个都行。名字和名字后面那句说明（「· 立刻做」）
  都能改。三个入口：点象限标题、右键标题（改名 / 在后面加一格 / 删这一格）、
  「更多 ▾ → 象限设置…」（一次改完）。新格子自动分配一个没用过的颜色，颜色不开放改。
  **删掉格子时里面的任务不会丢**，会搬到相邻那一格（删之前会问你）；至少要留一格。
- **每个象限最多 3 行卡片，多了翻页**：超出的折在「‹ 1/2 ›」后面，翻页器在象限标题行
  右端（旁边写着「共 N 条」）。这样一块长起来不会把同行的另一块一起撑高。
- **拖拽六件事**：改优先级、调同组顺序、拖到卡片上半张变子任务、子任务排序、
  子任务拖到空白提升成独立任务、**拖到右下角垃圾桶删除**（拖起来才现身）。
- **子任务**：卡面显示完成进度，**超过 3 条时右侧出 `‹ 1/2 ›` 翻页按钮**，
  右键可编辑 / 上下移 / 完成 / 删除 / 添加。**做完的自动沉底、第二天自动收起**
  （「已完成 N」胶囊点开就能看，摊开也**只算当天**）；每行右端有一行更小的字，
  没做完显示创建时间、做完了显示完成时间。
- **备注**：卡片上直接显示，双击就地改，空备注时有一行浅灰的「＋ 备注」入口。
- **创建 / 完成时间，精确到秒**：新建和勾完成时**自动记**下时刻，用小字贴在标题同一行
  的右端：「建于 10-26 15:04:09」/「完成 10-26 18:22:41」—— 复盘时既看得出哪天，
  也看得出几点几分几秒；「用时 2 天 2 小时」写在卡片底部那颗灰色药丸上。
  不想看见可以关（「更多 ▾ → 卡片上显示时间」），**关掉只是不显示，记录一直在**，
  而且关掉后时间也不再占宽度（标题能多放两个字）。
- **卡片高度按内容实算**：标题、备注、子任务各占各的行，下面不留空行
  （`CARD_H` 只是最小高度）。
- **已完成的任务第二天从板面收起**：数据不动，**点状态栏右下角的「已完成 N」
  （或顶栏「全部 ▾ → 已完成」）随时回看**，卡片上写着其中多少条已从板面收起。
- **卡片任何位置右键都能「添加子任务」**：子任务行铺满卡片时也不再是死角。
- **截止日期可以精确到时分秒，手写和选择都行**：点「＋ 日期」，左边填日期、右边填时间
  （留空 = 整天）。两格空着时有**浅灰的格式提示**（2026-10-15 / 18:30:05）；也能点着选 ——
  每格右边「▾」给常用值，**左边一张日历、右边一只钟面并排**，点哪天 / 哪一刻就填进去；
  **时间不用打冒号**（152413 = 15:24:13，1830 = 18:30，日期同理 20261026），
  离开输入框自动整理成标准写法，认不出的才报错。钟面上「时 / 分 / 秒」三个按钮切换，
  小时是一圈 00-23、分秒是 60 格，点哪一格就是哪一格。底下实时预览
  「→ 2026-10-15 18:30:00（周四）」，写错当场红字提示、不关窗。
  填了时间就按时间点算逾期（「已过 2 小时」变红），**到点提醒也到那个时刻才弹**；
  只填时间不填日期默认今天。「今天 / 明天 / 本周末」只改日期、保留已填的时间。
- **重复**：每天 / 每周 / 每月 / 每年 / **每周指定几天**（勾一三五这种）自动排下一次，
  而且**保持同一个时刻**（每天 18:30 的活，明天还是 18:30）。
- **子任务各有自己的重复**：默认跟着父任务（每轮都在），也可以单独设成
  **只出现这一次**，或者**只在周一三五出现** —— 父任务每走进下一轮时按这条规则筛。
  于是「一三五练胳膊、二四六练腿」用一个任务 + 两条子任务就能表达，周日那天两条都不带。
  没被带过去的那条留在上一轮那张卡里，不会丢。
- **计时**：点右下角药丸开始暂停，按日期分桶累计，可看今天 / 本周 / 近 7 天 / 全部。
- **统计与复盘面板**：各象限投入、完成趋势、12 周完成热力图。
- **导出与按月回顾**：「更多 ▾ → 导出完成记录（CSV）…」把全部完成记录导成表格
  （UTF-8 带 BOM，Excel 直接打开不乱码，可进透视表）；「按月回顾…」就地看这个月
  完成几条、覆盖几天、平均用时、每天柱状条和象限分布，也能单独导出这个月。
- **筛选与搜索**：全部 / 未完成 / 今天要做 / 已逾期 / 计时中 / 已完成；按标题、备注、
  子任务文字实时过滤。**搜索支持多词（空格分开 = 都要有）和排除词**（`复盘 -服务器`），
  命中的卡片边框会加深一道，不用逐字找。**状态栏那排数字本身就是按钮**（点一下切过去，深底的就是当前视图，
  再点一次回全部）；筛到空的时候画面上会给出「回到全部」的出口。
- **删除三条路，都进回收站**：右键「删除（进回收站）」／ 拖到右下角垃圾桶 ／
  点一下卡片选中后按 `Delete`（没选中时删鼠标指着的那张，在输入框里打字时不接管）。
  看不见的卡不会被删（切筛选后自动取消选中）。子任务也能拖进垃圾桶，只删那一条。
- **回收站 + 撤销**：删除进回收站可捞回（最多留 100 条）。`Ctrl+Z`（或状态栏那个
  「撤销」按钮）能退回**上一步**：删除、拖拽重排、改标题、改备注、改截止时间都算。
- **备份与导入**：每天自动备份到指定文件夹、可设保留天数；可从任意备份恢复。
- **到点提醒**：今天到期 / 已逾期的任务主动弹窗，窗口可置顶。
  **可设开机自启**（「更多 ▾ → 开机自动启动」，只写 HKCU 的 Run 项，不用管理员）——
  因为提醒挂在程序心跳上，程序不开就不会响；关着时错过的，下次打开会补上并说明
  「其中 N 条是之前就逾期的」。
- **免装 Python 的 exe**：一个 9.7 MB 的单文件，双击即用，可发给别人。

完整的按钮说明和快捷键表在程序里按 `F1` 打开「使用帮助」。

## 数据

任务明文存在程序目录的 `tasks.json` 里（顶层 `{v, ui, tasks, trash}`），
不上传、不加密，随时可以用记事本打开看。换电脑把这个文件夹拷过去就行。

**两台电脑共用一个文件**（比如整个目录放在网盘里）：保存前会看一眼磁盘有没有被
对方改过，改过就先把对方那份另存成 `tasks.remote-<时间>.json` 再写；反过来，如果
对方存了更新的版本而我这边还没动，板面会自动换成对方的。判断谁新用数据里的
`updated_at`（不看文件时间，网盘会改乱）。**不做自动合并**——冲突那份留在旁边自己看。

**这个文件被改坏也不会丢数据**：少个逗号、网盘同步到一半、磁盘坏块，导致读不出来时，
程序会先把原文件**原样改名**成 `tasks.broken-<日期>-<时间>.json`，再用示例数据启动，
并弹窗告诉你留底在哪。连改名都失败（文件被占用 / 没权限）时，这次运行**不会覆盖**
`tasks.json`，改动改写到 `tasks.recovered.json` —— 宁可让你找自己的改动，也不盖掉原始数据。

打包成 exe 之后也是同一套：**"程序目录"就是 exe 所在的那个目录**
（`_app_dir()` 里判了 `sys.frozen`，见源码导读机制⑬）。

程序自己产生的调试图、构建产物、日志、数据备份和临时文件都不入库（见 `.gitignore`）。

## 开发

- 回归测试：`python _selftest.py`（真实建窗驱动事件，当前 812 项）。
- 源码只有一个 `App` 类，顶部「代码导读」写了从哪读起（含 18 条必须弄懂的机制）。
- 改完代码想验证打包仍然正常：`_build_venv\Scripts\python.exe tools\build_exe.py`
  重打一次，再 `tools\verify_exe.py` 过一遍 —— 后者会在项目上一级建个
  `_exetest\` 当"朋友的电脑"，实测"数据确实写在 exe 旁边"，跑完随手删。
